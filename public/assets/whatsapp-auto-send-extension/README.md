# Kidzee School WhatsApp Auto-Send & Auto-Close Chrome Extension

This extension enables 100% hands-free WhatsApp Web sending for Kidzee School parent notifications.

## How to Install in Chrome or Edge (30 Seconds)
1. In Google Chrome or Microsoft Edge, go to:
   `chrome://extensions` (or `edge://extensions`)
2. In the top right corner, turn on **Developer mode**.
3. Click the **Load unpacked** button in the top left.
4. Select this `whatsapp-auto-send-extension` folder.
5. That's it! When EduNotify launches any parent notice in WhatsApp Web:
   - The extension automatically clicks the **Send** button.
   - Waits 2 seconds for message delivery.
   - Automatically closes the WhatsApp Web tab!
